# Домашнее задание к работе 6

## Условие задачи

Даны целые числа, указывающие число минут и часов (0-12). Вычислить время в минутах, когда часовая и минутная стрелка будут находиться на одной линии.

## 1. Алгоритм и блок-схема

### Алгоритм

1. Начало

2. Ввести значения часов H и минут M.

3. Нормализовать часы: если H == 12, то H = 0. Посчитать текущее время в минутах с начала полусуток.

4. Найти текущий временной интервал между моментами выстраивания стрелок (интервалы идут каждые 360 / 11 минут).

5. С помощью if-else определить точное время ближайшего совмещения на линии: если расчетная точка уже пройдена, взять следующий интервал. Округлить результат до ближайшей целой минуты.

6. Вывести итоговое время в минутах.

7. Конец

## 2. Реализация программы

```c
#include <stdio.h>
#include <math.h>

int main() 
{
    int H, M;
    
    printf("Введите количество часов (0-12) и минут: ");
    scanf("%d %d", &H, &M);

    int h_norm = H % 12;
    int current_total_minutes = h_norm * 60 + M;
    int interval_index = (int)(current_total_minutes * 11.0 / 360.0);
    
    double target_exact = (interval_index * 360.0) / 11.0;
    
    if (target_exact < current_total_minutes) 
    {
        
        target_exact = ((interval_index + 1) * 360.0) / 11.0;
    }
    else 
    {
        
        target_exact = target_exact; 
    }

    
    int result_minutes = (int)round(target_exact);

    printf("Время в минутах, когда стрелки будут на одной линии: %d\n", result_minutes);

    return 0;
}


```
